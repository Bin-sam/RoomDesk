RoomDesk 0.7.0 Windows 安装预览版。

## 下载

- **RoomDesk-Setup-0.7.0-win-x64.exe**：推荐，包含运行环境、快捷方式和卸载入口。
- RoomDesk-Portable-0.7.0-win-x64.zip：免安装版，解压后运行 RoomDesk.exe。
- SHA256SUMS.txt：文件 SHA-256 校验值。

适用 Windows 10 22H2 / Windows 11 x64。中文程序界面、英文安装向导，无需另装 .NET。安装包未签名。

## 本次更新

- 预订登记姓名、平台、联系电话，预订房态显示姓名，转入住自动带入。
- 预订和入住平台支持自由文本及可管理的常用气泡；移除身份证读卡器入口。
- 入住证件类型默认身份证，默认房价醒目显示，实际售出总价可修改。
- 房间批量新增、自由房型与常用气泡、酒店名称设置。
- 密码保护的房间删除与恢复；在住及预订房间禁止删除，历史入住和账单保留。
- 历史搜索索引、分页及数据库汇总，CSV 逐行生成，限制运行内存随历史数量增长。
- 房态图按可见楼层渲染并复用控件，减少大房量和反复刷新时的内存占用。
- WAL + FULL 提交落盘；每日在线增量备份，保留最近 7 份自动备份；手动备份不参与轮换。

## 数据与升级

数据位于 `%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db`。安装、升级和卸载均保留数据目录，安装包不携带用户数据库。升级前可在“数据与安全”手动备份。

首次运行仍有 24 间示例房，部分示例在住房没有入住登记；请先配置房间、默认价格及操作密码。账单是每次入住售出总价汇总，不等同实收流水；押金、退款、续住和换房尚未实现。

## 验证范围

发布前执行共享核心、HTTP/强制结束进程恢复、前台业务场景、百万条历史性能检查及 Windows WPF 内存检查；安装流程验证启动、重装与卸载的数据保留。性能原始报告随 GitHub Actions 构建保存。

Windows CI 环境为 Windows Server 2022，不等同于目标 Windows 10 电脑的人工 UI、缩放、硬盘及长期运行验收。性能阈值针对测试工作负载；全量 CSV 导出与备份可超过 1 秒，不承诺任意硬件或十年后所有数据规模下的固定延迟。
