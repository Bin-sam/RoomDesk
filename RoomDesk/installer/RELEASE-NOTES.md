RoomDesk 0.8.1 Windows 安装预览版。

## 本次更新

首次使用默认创建按酒店照片核对的 **33 间房**，4、5、6 楼各 11 间：

- 标准双人间：7 间。
- 豪华单人房：12 间。
- 豪华双人房：3 间。
- 商务双人房【棋牌】：9 间。
- 商务套房：2 间。

默认房型气泡同步更新。房间名称沿用房号，全部初始为空房待清扫，默认价格留空，待前台设置。完整对应表见仓库 RoomDesk/DEFAULT-ROOMS.md。

**已有酒店数据升级时保留原房间和所有业务记录，不自动覆盖或追加默认清单。** 已删除或编辑的默认房间也不会在重启时被重置。

保留 0.8.0 的软件内更新、房间及入住/预订编辑、5 分钟免密、删除后同号重加等功能。

## 安装与更新

- 推荐下载 **RoomDesk-Setup-0.8.1-win-x64.exe**，支持 Windows 10 22H2 / Windows 11 x64。
- 免安装版本：RoomDesk-Portable-0.8.1-win-x64.zip。
- 已安装 0.8.0：数据与安全 → 软件更新 → 检查更新 → 下载 → 备份并安装。
- 0.7 及更早版本需手动安装本版一次。

包含 .NET 运行环境，安装包未签名。数据库默认保存在 `%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db`，更新和卸载均保留。安装包不包含用户数据库。Mac 浏览器仅为共用业务逻辑的功能预览。

发布前检查默认房号/房型/楼层准确性、初始化幂等、旧库不覆盖、业务回归、Windows 安装流程、真实 0.8.0 → 0.8.1 更新助手升级及数据保留，并执行百万条历史性能和 WPF 内存检查。原始测试证据随发布附件提供。

Windows CI 使用 Server 2022，不等同于目标 Windows 10 的人工验收；性能结果适用于测试工作负载，不代表任意硬件十年运行保证。全量导出与备份可能超过 1 秒。
