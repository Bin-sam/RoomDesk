RoomDesk 0.8.3 Windows 安装预览版。

## 本次更新

- 房态卡片和字体按窗口可用宽高及可见房间数自动调整，不再固定使用大方框。
- 当前 33 间默认客房在常见桌面窗口中按楼层一屏显示；每层 11 间，减少滚动。
- 调整窗口大小、搜索或筛选房间时自动重新布局；只剩少量房间时限制卡片宽度。
- 保留房型加粗、醒目的待清扫状态及高对比度颜色。
- Windows 桌面与浏览器预览同步调整；大量房间或空间不足时保留最小可读字号及滚动，避免文字无限缩小。

## 下载与更新

- **RoomDesk-Setup-0.8.3-win-x64.exe**：Windows 10 22H2 / Windows 11 x64 安装包，包含运行环境。
- **RoomDesk-Portable-0.8.3-win-x64.zip**：免安装版。
- 已安装 0.8.0 及以上：打开“数据与安全”，滚动到底部，点击“软件更新 / 检查新版本”，再点击“检查更新”。
- 0.7 及更早版本需手动下载安装。

升级使用原数据库，不替换现有房间或入住记录。

## 本次发布范围

**按用户要求跳过测试，仅执行 Windows 编译、打包、校验值生成及发布。** 本次未运行核心、接口、前台业务、安装升级或性能测试，不沿用旧版本测试结果作为本版验证结论。发布文件附带 SHA256SUMS.txt。

安装包未签名。数据默认位于 `%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db`，安装包不含用户数据库。基于 Lantel C# 桌面模型，保留上游 MIT 许可证。
