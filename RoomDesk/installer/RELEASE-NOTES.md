RoomDesk 0.8.0 Windows 安装预览版。

## 下载

- **RoomDesk-Setup-0.8.0-win-x64.exe**：推荐，包含运行环境、快捷方式和卸载入口。
- RoomDesk-Portable-0.8.0-win-x64.zip：免安装版，解压后运行 RoomDesk.exe。
- SHA256SUMS.txt：文件 SHA-256 校验值。

适用 Windows 10 22H2 / Windows 11 x64。中文程序界面、英文安装向导，无需另装 .NET。安装包未签名。

## 本次更新

- **软件内更新**：数据与安全 → 软件更新。检测本仓库发布版本，下载并校验安装包；验证密码、备份数据后退出安装并自动重启。支持预览版版本比较，拒绝降级和不匹配的下载文件。
- **房间清单编辑**：每行“编辑”可修改楼层、自由房型、默认价格及合法房态；房态详情也提供入口。默认价不重写既有账单，在住和预订房不能直接变为空房绕过业务流程。
- **入住与预订资料编辑**：修改当前姓名、电话、平台及入住证件、备注、售出价。入住编辑保留原记录编号和时间；搜索及房卡同步更新。示例在住房补登资料时以保存时间为入住时间。
- **5 分钟免密**：验证后可选择短期免重复输入，关闭窗口仍有效；固定 5 分钟到期、立即锁定、密码修改或程序重启均会使授权失效。不保存明文密码。
- 保留 WAL + FULL 持久化、自动备份、分页搜索、房态控件复用及内存／性能发布检查。

## 首次启用更新功能

0.7 及更早版本尚无更新模块，需手动安装本版一次；之后可在 Windows 程序内点击更新。目标电脑需能访问 GitHub，失败时可继续使用原版或通过 Release 手动下载安装包。Mac 浏览器是共用业务逻辑的预览环境，只显示更新信息，不执行 Windows 安装器。

## 数据与升级

数据位于 `%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db`。安装、升级和卸载均保留数据目录，安装包不携带用户数据库。升级前可在“数据与安全”手动备份。

首次运行仍有 24 间示例房，部分示例在住房没有入住登记；请先配置房间、默认价格及操作密码。账单是每次入住售出总价汇总，不等同实收流水；押金、退款、续住和换房尚未实现。

## 验证范围

发布前执行共享核心、HTTP/强制结束进程恢复、前台业务场景、百万条历史性能检查及 Windows WPF 内存检查；安装流程验证启动、重装与卸载的数据保留，并使用真实 0.7.0 安装包验证更新助手升级到 0.8.0、自动重启及数据保留。性能原始报告随 GitHub Actions 构建保存。

Windows CI 环境为 Windows Server 2022，不等同于目标 Windows 10 电脑的人工 UI、缩放、硬盘及长期运行验收。性能阈值针对测试工作负载；全量 CSV 导出与备份可超过 1 秒，不承诺任意硬件或十年后所有数据规模下的固定延迟。
