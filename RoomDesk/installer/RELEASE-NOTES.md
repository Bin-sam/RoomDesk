RoomDesk 0.8.2 Windows 安装预览版。

## 本次更新

- 房态卡片字体整体放大：房号约 26、房型 18、住客文字 16、状态文字 18；相比 0.8.1，房号略小，房型更突出。
- 房型独立显示并加粗，较长名称可分两行，卡片更充分利用空间。
- 放大并加粗“待清扫”，清扫提示更醒目。
- 提高各房态文字、边框和底色的对比度，保留绿、蓝、黄、橙、紫等状态区分。
- 右侧房间详情同步放大文字。Windows 界面与浏览器预览同步调整。

保留 33 间默认客房、软件内更新、入住与预订编辑、5 分钟免密等原有功能。升级继续使用原数据库，不替换现有房间或入住记录。

## 下载与更新

- **RoomDesk-Setup-0.8.2-win-x64.exe**：Windows 10 22H2 / Windows 11 x64 安装包，包含运行环境。
- **RoomDesk-Portable-0.8.2-win-x64.zip**：免安装版。
- 已安装 0.8.0 / 0.8.1：打开“数据与安全”，滚动到底部，点击“软件更新 / 检查新版本”，再点击“检查更新”。
- 0.7 及更早版本需手动下载安装。

## 本次发布范围

**按用户要求跳过测试，仅执行 Windows 编译、安装包打包、校验值生成及发布。** 本次未运行核心、接口、前台业务、安装升级和性能测试，不将旧版本测试结果作为本版验证结论。发布文件附带 SHA256SUMS.txt。

安装包未签名。数据默认位于 `%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db`，安装包不含用户数据库。基于 Lantel C# 桌面模型，保留上游 MIT 许可证。
