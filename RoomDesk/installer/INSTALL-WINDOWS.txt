栖间 RoomDesk 0.8.3 预览版 — Windows 安装说明

1. 运行 RoomDesk-Setup-0.8.3-win-x64.exe，按安装向导完成安装。
   适用 Windows 10/11 x64；目标 Windows 10 22H2。包含 .NET 运行环境。
   向导为英文，程序界面为中文。无需管理员权限。
2. 从开始菜单或桌面打开 RoomDesk。
3. 默认数据：%LOCALAPPDATA%\RoomDeskPrototype\rooms-v1.db。
   升级和卸载均保留该数据目录；升级前建议在“数据与安全”中备份。
4. 首次使用含 33 间默认房（4、5、6 楼各 11 间），均为空房待清扫，价格留空。
   已有数据升级时保留原房间、价格及记录，不自动替换或追加默认房间。
   这是功能验证原型，请先核对并配置房间、默认价格和操作密码。
5. 当前价格是每次入住总价，账单不是收款流水。
   已移除身份证读卡器入口，入住信息手动填写或从历史记录匹配。
6. 本安装包没有代码签名证书。发布的 SHA256SUMS.txt 可用于校验下载完整性。
   Windows 10 实际安装、缩放、界面流畅度仍需目标电脑验收。

上游：https://github.com/GideonLartey/hotel-management-system

软件内更新：数据与安全 → 软件更新 → 检查更新 → 下载 → 备份并安装。
0.7 及更早版本需要先手动安装本版一次，此后可在软件内更新。
更新前须结束当前业务并验证操作密码；下载文件经 SHA-256 校验，
助手在程序退出后安装，随后自动重启并继续使用原数据库。
目标电脑需能访问 GitHub；网络失败时可继续使用当前版本或手动下载安装包。
操作密码可选择验证后 5 分钟免重复输入；关闭弹窗仍有效，退出程序或修改密码后失效。
“立即锁定免密授权”可提前结束授权。
房间清单“编辑”可修改楼层、房型、默认价与合法房态；房态页可编辑入住或预订资料。
